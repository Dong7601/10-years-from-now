1　水溶液と電流 ― 電解質と非電解質

食塩水に電極を入れて電源につなぐと、豆電球がつく。ところが砂糖水では、同じようにしても豆電球はつかない。水にとけたときに電流が流れる物質と、流れない物質があるのだ。

水にとかしたとき、その水溶液に電流が流れる物質を電解質という。塩化ナトリウム・塩化銅・塩化水素・水酸化ナトリウムなどが電解質である。いっぽう、水にとかしても電流が流れない物質を非電解質という。砂糖やエタノールは非電解質である。

AIレイヤー

電解質も非電解質も、水にはとける。ちがいは「とけるかどうか」ではなく、とけたときに電気を帯びた粒子ができるかどうかにある。

💡第8問で「砂糖はとけていないから」と書いていたね。砂糖はちゃんととけている。でも粒が電気を帯びないから電流が流れない――「とける」と「電離する」は別の話だよ。

2　原子の構造とイオン

原子のつくり

原子の中心には原子核があり、そのまわりを電子が回っている。原子核は、＋の電気をもつ陽子と、電気をもたない中性子からできている。電子は－の電気をもつ。ふつうの原子では陽子の数と電子の数が等しいので、原子全体としては電気を帯びていない。

図2　原子のモデル。＋と－の数がつり合っている。

イオンとは

原子が電子を失ったり受け取ったりすると、＋と－のつり合いがくずれ、原子全体が電気を帯びる。このように電気を帯びた粒子をイオンという。

原子が電子を失うと、－が減るので全体として＋の電気を帯びる。これを陽イオンという。原子が電子を受け取ると、－が増えるので全体として－の電気を帯びる。これを陰イオンという。

POINT
電子を失う → 陽イオン（＋）　／　電子を受け取る → 陰イオン（－）
※電子そのものが－の電気をもつので、「失うと＋になる」ことに注意。

イオンの表し方

イオンは、元素記号の右上に、帯びている電気の種類（＋・－）と数を書いて表す。これをイオン式という。数が1のときは書かない。

陽イオン水素イオン H⁺　ナトリウムイオン Na⁺　銅イオン Cu²⁺　亜鉛イオン Zn²⁺　マグネシウムイオン Mg²⁺　アンモニウムイオン NH₄⁺
陰イオン塩化物イオン Cl⁻　水酸化物イオン OH⁻　硫酸イオン SO₄²⁻　硝酸イオン NO₃⁻

電離

電解質が水にとけて、陽イオンと陰イオンに分かれることを電離という。電離した水溶液の中では、電気を帯びた粒子（イオン）が自由に動き回っているので、電流が流れる。電離のようすを化学式とイオン式で表したものを電離式という。

NaCl → Na⁺ ＋ Cl⁻

HCl → H⁺ ＋ Cl⁻

CuCl₂ → Cu²⁺ ＋ 2Cl⁻

NaOH → Na⁺ ＋ OH⁻

電離式では、左右で原子の数が等しく、＋と－の電気の合計も等しい（塩化銅なら 2＋ と 1－×2 でつり合う）。

3　電気分解とイオン

塩化銅水溶液の電気分解

青色の塩化銅水溶液に炭素棒の電極を入れて電流を流すと、陰極（電源の－極につないだ側）には赤色の銅が付着し、陽極（電源の＋極につないだ側）からは刺激臭のある塩素が発生する。

これは、水溶液中の銅イオン Cu²⁺ が陰極に引き寄せられて電子を2個受け取り、銅原子になるためである。いっぽう塩化物イオン Cl⁻ は陽極に引き寄せられ、電子を1個ずつ失って塩素原子になり、2個結びついて塩素分子 Cl₂ として出ていく。

陰極：Cu²⁺ ＋ 2e⁻ → Cu

陽極：2Cl⁻ → Cl₂ ＋ 2e⁻

全体：CuCl₂ → Cu ＋ Cl₂
図3　塩化銅水溶液の電気分解。陽イオンは陰極へ、陰イオンは陽極へ引かれる。

塩酸の電気分解

塩酸（塩化水素の水溶液）を電気分解すると、陰極から水素、陽極から塩素が発生する。塩化水素は HCl → H⁺ ＋ Cl⁻ と電離しており、水素イオン H⁺ が陰極で電子を受け取って水素分子 H₂ になる。

陰極：2H⁺ ＋ 2e⁻ → H₂

陽極：2Cl⁻ → Cl₂ ＋ 2e⁻

塩素は水にとけやすいため、集まる気体の体積は水素のほうが多く見える。

4　電池のしくみ

金属のイオンへのなりやすさ

硫酸銅水溶液に亜鉛板を入れると、亜鉛板の表面に赤い銅が付着し、水溶液の青色がうすくなる。これは、亜鉛が銅よりもイオンになりやすいため、亜鉛原子が電子を失って亜鉛イオンになり、代わりに銅イオンがその電子を受け取って銅原子になったからである。

金属には、イオンへのなりやすさに差がある。中学校で扱う金属では、次の順になる。

イオンになりやすい　Mg ＞ Zn ＞ Cu　なりにくい

この「なりやすさの差」が、電池から電気を取り出せる理由のもとになっている。

電池（化学電池）

化学変化によって物質がもつ化学エネルギーを電気エネルギーとして取り出す装置を電池（化学電池）という。電池の中では、電子のやりとりをともなう化学変化が起きている。

ダニエル電池

ダニエル電池は、硫酸亜鉛水溶液にひたした亜鉛板と、硫酸銅水溶液にひたした銅板を、素焼きの板で仕切ってつくる。2つの金属板を導線でつなぐと、電流が流れる。

図4　ダニエル電池のモデル図。●は電子、○はイオンを表す。●は導線の中を、○は水溶液の中を進む。

亜鉛板の表面では、亜鉛原子が電子を2個失って亜鉛イオン Zn²⁺ となり、水溶液の中へとけ出していく。失われた電子は亜鉛板に残される。

亜鉛板（－極）：Zn → Zn²⁺ ＋ 2e⁻

電流の向きと＋極・－極

電子が移動する向きと、電流が流れる向きは逆である。電子は亜鉛板から銅板へ移動するが、電流は銅板から亜鉛板へ流れると決められている。電流が流れ出る側の電極を＋極、流れこむ側の電極を－極という。ダニエル電池では、銅板が＋極、亜鉛板が－極である。

まとめ
イオンになりやすい金属（亜鉛）が－極、なりにくい金属（銅）が＋極。イオンへのなりやすさの差が大きいほど、電圧は大きくなる。

いろいろな電池

使うと電圧が下がって元にもどらない電池を一次電池（マンガン乾電池・アルカリ乾電池など）、外部から逆向きに電流を流す（充電）ことでくり返し使える電池を二次電池（鉛蓄電池・リチウムイオン電池など）という。また、水素と酸素が結びついて水ができる化学変化から電気エネルギーを取り出す燃料電池は、排出物が水だけなので環境への負担が小さい。

5　酸とアルカリ

酸性・アルカリ性の水溶液

塩酸や硫酸などの水溶液は、青色リトマス紙を赤色に変え、マグネシウムなどの金属と反応して水素を発生させる。このような性質を酸性という。水酸化ナトリウム水溶液などは、赤色リトマス紙を青色に変え、フェノールフタレイン溶液を赤色に変える。このような性質をアルカリ性という。

指示薬酸性中性アルカリ性
リトマス紙青 → 赤変化なし赤 → 青
BTB溶液黄色緑色青色
フェノールフタレイン溶液無色無色赤色
マグネシウムリボン水素が発生反応なし反応なし

酸・アルカリの正体

水溶液にしたとき、電離して水素イオン H⁺ を生じる物質を酸という。酸性の性質は H⁺ による。いっぽう、電離して水酸化物イオン OH⁻ を生じる物質をアルカリという。アルカリ性の性質は OH⁻ による。

酸：HCl → H⁺ ＋ Cl⁻　　H₂SO₄ → 2H⁺ ＋ SO₄²⁻

アルカリ：NaOH → Na⁺ ＋ OH⁻　　Ba(OH)₂ → Ba²⁺ ＋ 2OH⁻

このことは、電流を流す実験で確かめられる。pH試験紙の中央に塩酸をしみこませて電圧を加えると、赤色の部分が陰極側へ広がる。酸性のもとになる粒子（H⁺）が＋の電気を帯びているからである。

pH（ピーエイチ）

酸性・アルカリ性の強さはpHで表す。pHは0〜14の値で、7が中性、7より小さいほど酸性が強く、7より大きいほどアルカリ性が強い。

6　中和と塩

塩酸に水酸化ナトリウム水溶液を少しずつ加えていくと、酸性がしだいに弱まり、やがて中性になる。これは、酸の水素イオン H⁺ とアルカリの水酸化物イオン OH⁻ が結びついて水ができ、たがいの性質を打ち消し合うからである。この反応を中和という。

H⁺ ＋ OH⁻ → H₂O

中和では、水といっしょに、酸の陰イオンとアルカリの陽イオンが結びついた物質もできる。この物質を塩（えん）という。塩酸と水酸化ナトリウム水溶液の中和でできる塩は塩化ナトリウムで、水溶液を蒸発させると白い結晶が残る。

HCl ＋ NaOH → NaCl ＋ H₂O

H₂SO₄ ＋ Ba(OH)₂ → BaSO₄ ＋ 2H₂O

硫酸と水酸化バリウム水溶液の中和でできる塩は硫酸バリウムで、水にとけにくいため白い沈殿として現れる。

図6　中和のモデル。
POINT
中和が起きている間、H⁺ の数は減り、OH⁻ は水になるので水溶液中には増えない。ちょうど中性になったところで H⁺ と OH⁻ の両方が0になり、さらにアルカリを加えると OH⁻ が余ってアルカリ性になる。

身近な中和の例：胃薬（胃酸を中和する）、酸性の土に石灰をまく、虫さされにアンモニア水をぬる。
